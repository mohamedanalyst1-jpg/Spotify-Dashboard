#  Spotify Music Streaming Analysis Dashboard

An interactive **Power BI** dashboard that analyzes Spotify streaming performance across languages, genres, artists, and listener demographics.

![Dashboard Preview](screenshot.png)

##  Overview

The dashboard answers questions such as:

- How many total streams are there, and how do they split between **solo**, **lead**, and **feature** streams?
- Which **languages** and **genres** drive the most streams?
- Who are the **top streamed artists**?
- How are streams distributed by **artist sex**?

## Key Metrics

| Metric | Value |
|---|---|
| Total Streams | 8.41M |
| Total Solo Streams | 4.16M |
| Total Lead Streams | 6.07M |
| Total Feature Streams | 2.34M |
| Male / Female stream share | ~79.7% / ~20.3% |

##  Visuals Included

- **KPI cards** – total, solo, lead, and feature streams
- **Streaming Performance by Language** – English, Spanish, Portuguese, Hindi, Korean, and more
- **Streaming Performance by Genre** – Hip-Hop, Pop, Reggaeton, Rock, R&B, Latin, EDM, K-Pop, and more
- **Top Streamed Artists** – led by Drake, Taylor Swift, Bad Bunny, The Weeknd, and others
- **Streaming Distribution by Sex** – donut chart
- **Slicers** – filter by *Artist Type* and *Country*

##  Tools

- Microsoft Power BI Desktop
- DAX measures and data modeling

##  How to Use

1. Clone or download this repository.
2. Open `Spotify Dashboard.pbix` in [Power BI Desktop](https://powerbi.microsoft.com/desktop/) (free).
3. Use the slicers to explore the data.
